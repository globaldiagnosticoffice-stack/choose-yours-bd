# Choose Yours BD Pro

A modern responsive e-commerce website built with Next.js.

## Features
- Home page
- Product categories
- Shop with filters and sorting
- Product detail page
- Size selection
- Cart with quantity controls
- Checkout form
- Inside/Outside Dhaka delivery charge
- Cash on Delivery, bKash and Nagad options
- Responsive mobile design
- Contact number: 01867-037489

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Upload all files to your GitHub repository, then import the repository into Vercel and click Deploy.
